# AL AI Bot Runtime v5.0.0 — Foundation Release

This release is a **non-destructive foundation refactor**. Existing runtime features remain the contract; the goal is simpler operations, safer contribution rules and less operational friction.

## Included

- one-command bootstrap: `npm run bootstrap`;
- one foreground launcher: `npm run start:all`;
- exact dependency installation through the committed lockfile;
- automatic local adapter secret generation;
- repository syntax/config/security checks before startup;
- explicit architecture and operations documentation;
- mandatory AI/developer guardrails in `AGENTS.md`;
- security/data-handling policy in `SECURITY.md`;
- no new runtime framework and no new UI dependency;
- existing single-gateway, bounded-pipeline, MCP/HMAC and Windows-safe process architecture preserved.

## Compatibility

The runtime package remains on the existing `4.5.0` package metadata until the lockfile is regenerated by the release environment. This document is the release baseline rather than a package-version mutation.

## Release gate

Before tagging a final v5 release, run:

```powershell
npm ci
npm run check
npm run security:check
npm run lint
npm test
```

Then perform a live smoke test covering gateway readiness, `/health`, `/metrics`, adapter authentication, config validation, shutdown and restart.
